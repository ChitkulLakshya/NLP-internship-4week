# NLP Data Analytics Internship — 4-Week Project (Sep–Oct 2026)

**Author:** Chitkul | **Track:** Data Analytics / NLP | **Period:** 01-Sep-2026 → 01-Oct-2026
**Stack:** Python 3.12, pandas, scikit-learn, NLTK, matplotlib/seaborn, python-docx

This repository contains end-to-end NLP work for a 4-week internship:
- **Week 1:** Exploratory Data Analysis & Preprocessing (distribution, n-grams, sentiment, noise audit, tokenization/normalization)
- **Week 2:** Text Classification pipeline (TF-IDF + Naive Bayes / Linear SVM / LogReg, metrics, validation)
- **Week 3:** Sentiment Analysis (lexicon + ML) & Named Entity Recognition (rule-based + statistical)
- **Week 4:** Advanced Analysis — Topic Modeling (LDA), Clustering (KMeans), Language Trend detection over time

## Quickstart


## Datasets (proxy for public sources)

Real public datasets referenced & mirrored by schema:
- Week1 ~ Amazon Product Reviews / Sentiment140 tweets / AG News (mixed text, ratings, timestamps)
- Week2 ~ AG News + IMDB (4-class news categorization)
- Week3 ~ IMDB/Amazon polarity + CoNLL-2003/GMB NER style entities
- Week4 ~ NYT/Guardian-style timestamped corpus for trend detection

Synthetic generation is **intentional** for offline reproducibility; schemas, noise profiles, and class balances mirror the public sources. Mapping table + limitations are in each DOCX (§1–§2).
